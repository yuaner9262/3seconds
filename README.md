# 3秒

原创爱情交互叙事的第一版技术原型。以原创生成的黑白书店场景验证「街景 → 手镜倒影 → 目光」三层连续探索。已参考用户提供的概念图；未查阅原作页面，不代表对原作的复现。占位素材的线描精度和真实反射细节明显低于概念参考。

## 开发

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
npm run build
npm test
npm exec playwright test
```

端到端测试使用 `/usr/bin/chromium`；其他机器请修改 `playwright.config.js` 的浏览器位置或使用 Playwright 安装的浏览器。

滚轮/触控板以指针为中心缩放；拖动平移；触屏支持双指缩放。探索过程没有文字或操作按钮，通过滚轮/触控板缩放进入和返回，拖动平移；最后一层才显示重新开始按钮。键盘快捷键作为备用。当前不启用摄像头。

## 素材与空间

`src/story.js` 定义画布尺寸与层级；图片在 `public/art/`。`portal` 的 x/y/width/height 为相对于父图左上角的 0–1 坐标，child 指向子层。子图直接嵌入该区域，无阈值换图；`camera.js` 组合坐标并执行指针锚定缩放。新增层无需修改相机逻辑。当前内容链为单入口；分叉需扩展阅读路径模型。

每个入口须与下一层完整画面的内容对应，尤其是边缘、透视与明暗。当前矩形嵌入用于证明空间连续性；不是光学上精确的曲面反射。生产素材可用高分辨率图，深层细节用独立素材承接；当前主图为 1586×992 的生成图，后两层复用同源裁切以保证坐标完全衔接；深层可见像素化，尚不是独立高精度的深层插画。旧矢量占位素材保留供开发使用。正式手绘图需要重新校准入口；非同宽高比素材会按入口比例拉伸，应统一比例或相应调整入口尺寸。

`window.narrativeControls` 提供 zoom(factor, point)、pan(x,y)、go(index)、reset()，未来手势适配器复用这些方法，不预设识别方案。分格与分页打印尚未实现；可基于同一 layers 数据添加布局配置与导出渲染器。

## 当前验证边界

构建、相机数学测试、桌面/移动浏览器的导航、滚轮、拖动、重置、素材加载与弹窗验证。未做真实摄像头、实体触控板或打印设备验证。项目不依赖外部字体、接口或密钥。始终以无文字画面阅读。

## 单文件预览

运行 `npm run preview:file` 生成 `dist/3seconds-preview.html`。图片、样式和脚本均嵌入其中，下载后用桌面浏览器打开，无需服务端。云端受管浏览器禁止 file: 导航，因此自动验证以本地 HTTP 提供该单文件，另检查其不依赖任何外部请求。
